# Table ownership registry: PER-R23 in docs/spec/platform/persistence.md.
#
# TestSQLAccessFollowsTableOwnership (table_ownership_test.go) reads the SQL
# text of every non-test Go file under api, cmd, internal and tools. It fails
# on an access that this file does not allow, and on an entry here that no
# longer matches an access. TestTableOwnershipMatchesTheSchemaDocuments keeps
# scripts/erd/meta.json and the "Table owners" table of persistence.md in step
# with [relations], and the PostgreSQL integration test of
# internal/persistence/postgres requires the migrated schema to have exactly
# these tables and views.
#
# A write is INSERT, UPDATE, DELETE, MERGE, TRUNCATE, COPY FROM or pgx
# CopyFrom, LOCK TABLE, a change of the definition, or an exclusive row lock:
# FOR UPDATE or FOR NO KEY UPDATE. A read is any other use, including FOR SHARE
# and FOR KEY SHARE.
#
# Blank lines and lines starting with # are ignored. An indented line
# continues the reason of the entry above it.
