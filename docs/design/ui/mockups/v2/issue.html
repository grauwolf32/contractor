IDOR: Any authenticated user can read any mechanic’s service report

Needs your reviewCWE-639GET/workshop/api/mechanic/mechanic_report
What is wrong

GetReportView.get (crapi/mechanic/views.py:214-244) is protected only by @jwt_auth_required. Its query ServiceRequest.objects.filter(id=report_id).first() at line 235 is not scoped to the caller. Sibling views scope by mechanic__user=user (line 269) and check the mechanic role (line 304).

Impact

Any signed-in user, including a self-registered customer, can step through sequential report_id values and read every service report — owner email, phone, VIN and problem details.
