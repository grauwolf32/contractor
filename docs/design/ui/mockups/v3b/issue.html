IDOR: Any authenticated user can read any mechanic's service report

Endpoint
GET/workshop/api/mechanic/mechanic_report
Weakness
CWE-639, authorization bypass through a user-controlled key
Severity
Not set

What the AI found

GetReportView.get in crapi/mechanic/views.py (lines 214–244) is protected only by @jwt_auth_required. The query on line 235 is not scoped to the caller. Sibling views do scope theirs: line 269 filters by mechanic__user=user and line 304 checks the mechanic role.

Impact

Any signed-in user, including a self-registered customer, can enumerate sequential report IDs and read every service report: owner email, phone, VIN and problem details.

What the AI is unsure about

It needs a valid token from the external identity service. How that service issues tokens isn't visible in this code.
