# Rationale — material-formats-v1

The override sheet gives each surface its own hierarchy instead of repeating the same card look: OpenAPI gets a sunken operation rail with fixed-width method badges and chip-style path/response codes, the LikeC4 diagram gets a banded toolbar above a spacious rounded canvas, and the archive gets an uppercase directory list with tree-guide rails, mono file sizes, and chip-style file paths. Everything is scoped to the existing format classes and built only from the shared color/font tokens, so the header, rail, support column, fonts, behaviors, and all three themes (light/dark/black) stay untouched. Media rules at 1100px and 820px strip the panel chrome back to the seed's stacked layout and tighten canvas, paddings, and badges so 390/320px viewports remain overflow-free.
