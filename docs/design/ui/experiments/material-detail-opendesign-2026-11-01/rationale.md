# Rationale — material-polish-v2

This pass layers ~100 lines of token-only CSS after the seed so the reader panel, not chrome, owns the page: a tighter compact header with ghost copy/download actions, an outline type badge, flush underline tabs, and a slightly narrower quiet supporting column at a wider 32px gutter. Reading quality improves through border-free code insets with slim themed scrollbars, a single quiet HTTP summary block with evenly spaced header rows, and a calm 70ch document measure with styled inline code — all using only existing theme tokens and system sans/mono. Responsive overrides keep every control wrapping with no sideways overflow at 390/320px (36px touch targets, stacked actions, tightened paddings), and the next component-level step would be folding this composition directly into the seed markup once behavior is frozen.
