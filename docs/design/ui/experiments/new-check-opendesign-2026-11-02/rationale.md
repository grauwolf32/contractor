# Rationale — new-check-polish-v1

The redesign reads as a composed workspace rather than a stack of identical cards: the objective leads in a quiet elevated field, and the workbench divides into three visually distinct zones — a flat, borderless check-type list for easy row-to-row comparison (selection marked by weight, tint, and an inset accent bar, never color alone), the setup stage as the single raised surface with hairline-separated sections instead of nested boxes, and a compact sticky launch summary whose mono, tabular fact rows and full-width tone strip make readiness scannable. Materials render as attached-file rows — mono selects and faint exact-revision hints — while empty slots stay calm dashed drop targets so missing state reads as actionable, not alarming; badges keep the semantic green/amber/red token mapping with text labels. All colors come from existing theme tokens (light/dark/black adapt automatically), fonts stay `var(--font-sans)` / `var(--font-mono)`, spacing follows the 4/8 scale, and visible `:focus-visible` rings plus `prefers-reduced-motion` support are included. At 1100px the summary becomes a two-column band below setup; at phone widths everything returns to normal flow with larger touch targets, no floating region, and a single-column action stack by 320px. No JavaScript, ids, fixtures, fonts, or theme variables were changed; the stylesheet is a pure override layer inserted before `</head>`.
