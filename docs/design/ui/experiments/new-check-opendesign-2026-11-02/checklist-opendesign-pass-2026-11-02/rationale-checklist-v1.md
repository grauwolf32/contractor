# Rationale — checklist-polish-v1

The editor now borrows the summary's card language (hairline `--line` border, `--radius-lg`, inset `--surface-subtle`) instead of its heavier `--line-strong`/`--radius-md` shell, so the two working surfaces read as one composed pair while the material slots keep their smaller radius. Items stay a single calm list with hairline separators, the mono ordinal and remove button are top-aligned to the statement's first line (`calc(var(--space-2) + 1px)`) with tabular numerals, and the placeholder was lifted from `--faint` to `--muted` for readable empty-state guidance. "Add item" keeps its lightweight accent treatment while "Use checklist" is demoted from a filled chip to a bordered neutral secondary (clearly readable when disabled, success tones when applied), leaving Start check as the page's only primary action in the summary. At 720px and 340px the header type steps down, entry padding tightens, and editor/statement padding compresses — all in normal flow with long statements wrapping and remaining editable, using only existing Contractor tokens.
