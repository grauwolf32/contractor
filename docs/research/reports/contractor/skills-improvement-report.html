Missing XXE / XML-parsing sink category
high
references/sinks.md + cwe-mapping.md
Gap
No XML/XXE sink anywhere. `parser.process` is the only generic parser label; no `parser.xml` / external-entity concept, no safe-flag sanitizer guidance, and CWE-611 is absent from the mapping. XXE is one of the most common static-analysis findings in Java/.NET/PHP.
Evidence
semgrep-rules has ~20 XXE rules: java/lang/security/xmlinputfactory-possible-xxe.yaml, csharp/.../xxe/xmldocument-unsafe-parser-override.yaml, xmltextreader-unsafe-defaults.yaml. The Java rule keys on missing hardening flags: isSupportingExternalEntities=false and XMLConstants.FEATURE_SECURE_PROCESSING.
Recommendation
Add allowed label `parser.xml.unsafe` (vs `parser.xml`) and a sinks row:
### parser.xml.unsafe — XML parser created without disabling DTD/external entities (no disallow-doctype-decl, no FEATURE_SECURE_PROCESSING; .NET XmlResolver not null; PHP no libxml_disable_entity_loader/LIBXML_NONET); tainted XML body parsed -> XXE (file read / SSRF) -> CWE-611.
Add cwe-mapping row: | XML External Entity (XXE) | CWE-611 | parser.xml.unsafe |
