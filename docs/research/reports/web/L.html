L · Ensemble & diversity

Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

L1 — Diverse-lens finders, unioned + deduped, beat a single generalist pass

MultiVer: Zero-Shot Multi-Agent Vulnerability Detection
Almost exactly L1: four agents each look through a different dimension (security flaw, correctness, performance, style) and union-vote — flag if any agent fires. Achieves 82.7% recall on PyVul, beating fine-tuned GPT-3.5. Direct evidence the union-of-lenses raises recall.
VulAgent: Hypothesis Validation-Based Multi-Agent System
A MetaAgent routes code to specialized analyzers (memory safety, authz, file I/O, concurrency) so each holds a single concern — explicitly lowers per-agent reasoning complexity and increases coverage of sensitive statements. The per-class lens design L1 proposes.
MulVul: Retrieval-Augmented Multi-Agent Code Vulnerability Detection
Argues vulnerability patterns are too heterogeneous for one unified detector (pointer arithmetic vs taint tracking need different reasoning) — the theoretical justification for splitting into per-class lenses rather than one generalist pass.
Dipper: Diversity in Prompts for Producing LLM Ensembles in Reasoning
Training-free inference-time ensemble: feed one model a diverse prompt set in parallel to elicit varied reasoning paths. A cheap way to manufacture lens diversity from a single small model without N separate model deployments.

L2 — An adversarial (majority-refute) verifier raises precision more than it costs recall

Minimizing Hallucinations: Adversarial Debate and Voting in LLM-Based Multi-Agents
Adversarial debate + voting cross-validates outputs across diverse agents to suppress single-model errors — the methodological core of a majority-refute panel that drops findings the skeptics overturn.
Chain-of-Verification Reduces Hallucination in Large Language Models
Decoupled draft→plan-verification→execute→synthesize loop; forcing independent verification cuts hallucination. A single-agent analog of the refute panel, useful when N skeptics is too expensive.
Strategic Heterogeneous Multi-Agent Architecture for Cost-Effective Code Vulnerability Detection
Cooperative coalition with union aggregation PLUS a "verification game" where a verifier can override expert consensus — exactly the adversarial-verifier-on-top-of-ensemble shape (combines L1 union with L2 refute).
Verify when Uncertain: Beyond Self-Consistency in Black-Box Hallucination Detection
Targets verification effort at uncertain cases rather than verifying everything — a way to size the refute panel by confidence so precision gain ≫ recall/cost loss.

L3 — Ensemble diversity helps small models disproportionately

SLM-MUX: Orchestrating Small Language Models for Reasoning
Most relevant to the mission: orchestration designed for frontier models paradoxically degrades SLMs by amplifying errors; SLM-MUX instead selects by self-consistency and gains up to +13.4% on MATH. A model-selection search picks the most complementary small models — directly informs ensemble design for 27b.
Dipper (full text) — 3× Qwen2-1.5B beats a 7B model on MATH
Concrete small-model asymmetry datapoint: a training-free ensemble of three 1.5B instances outperforms a single 7B. The recall-uplift-by-model-size signature L3 wants to confirm.
SLM-MUX (PDF) — model selection + test-time scaling for SLMs
Caveat-bearing source: warns discussion-based (debate) orchestration can hurt small models via error amplification, favoring confidence-selection/union instead — a design constraint for any 27b ensemble, against naive multi-agent debate.
