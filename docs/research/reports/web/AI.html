AI · Selective escalation to frontier models

Web-sourced prior art on optional, targeted escalation from a small model to a frontier model. Links are real web-search results; relevance notes are the researcher's synthesis. The dominant precedent — LLM cascades — escalates by confidence, which directly informs the where/when/how questions.

AI1 — escalate at stuck/hard points, cheaply (escalation is rare)

AutoMix: Automatically Mixing Language Models (NeurIPS 2024)
A small model self-verifies its own output and a POMDP router escalates to a larger model only when confidence is low — >50% cost reduction at comparable quality. The canonical "small does most, big handles the hard cases" design; the stuck/low-confidence trigger is exactly AI1.
FrugalGPT: Using LLMs While Reducing Cost and Improving Performance
LLM cascade queries the smallest model first and escalates only when the answer isn't good enough — matches GPT-4 at up to 98% lower cost because escalation is the exception, not the rule. Quantifies "rare escalation stays cheap in aggregate."

AI2 — escalate only contested/low-confidence items = cost-optimal cascade

RouteLLM: Learning to Route LLMs with Preference Data (ICLR 2025)
Trains a router that predicts when a strong model is actually needed and sends only those queries up — >2× cost reduction at no quality loss, generalizing to unseen model pairs. Direct evidence that escalating only the hard subset beats escalate-all/none.
FrugalGPT (cascade by confidence)
The confidence-thresholded cascade is the cost-optimal selector: cheap model answers the easy majority, expensive model is reserved for the uncertain tail.
Cascaded Language Models for Cost-Effective Human–AI Decision-Making
Base model → verify correctness probability → defer to larger model if uncertain → abstain to a human if still uncertain. A three-tier confidence cascade; the verdict-escalation pattern AI2 proposes for contested findings.

AI3 — frontier-seeded hypotheses + small-model verification (and on-the-job learning)

From Deferral to Learning: Online In-Context Knowledge Distillation for LLM Cascades (Inter-Cascade)
When the strong model resolves a deferred case it emits a generalized, reusable strategy stored for the weak model — turning a one-off escalation into durable uplift without fine-tuning. Frontier "seeds," small model reuses; ties this direction to O (experience memory).
AutoMix
Few-shot self-verification means the small model can decide what to escalate for generation and still do the bulk of verification locally — the asymmetry AI3 exploits (few frontier tokens to generate, cheap local verification).

AI4 — which insertion point gives the best quality-per-escalation-token

Cascade-Aware Training of Language Models
Trains models to be good cascade members — shows the deferral/escalation decision point materially changes the cost/quality frontier, motivating AI4's search for the highest-leverage insertion point.
LLM Cascade with Multi-Objective Optimal Consideration
Optimizes the cascade jointly over cost and quality — the framework for ranking candidate escalation points (planner vs hypothesis-gen vs verify vs stuck-retry) by quality per escalation-token.
Bi-directional Model Cascading with Proxy Confidence
Uses proxy confidence to decide both when to escalate and when to fall back — relevant to placing the trigger at the right stage rather than a fixed point.

AI5 — optional, config-gated, drop-in (and explicit opt-in for data-residency)

RouteLLM (cost-threshold knob)
Routing is governed by a single cost threshold — the natural shape for an optional config knob that is a no-op at one extreme and full-escalation at the other; drop-in because only the model selection changes.
Managing context on the Claude Developer Platform (Anthropic)
Background on swapping/managing model behaviour via config; the integration here keeps tools/prompt/schema identical and only swaps the model alias for one call. (Data-residency caveat — escalation sends code off-box — is a design requirement, not a cited result.)

AI6 — the cost/quality frontier: rare×targeted ≈ small-only cost, near-frontier quality

FrugalGPT (cost–quality curve)
Demonstrates the Pareto frontier directly: matching the best single model at a fraction of cost, or beating it at equal cost — the curve AI6 wants to plot for all-small vs cascade vs all-frontier.
AutoMix (>50% cost cut at comparable quality)
Concrete point on that frontier for a small→large cascade; the aggregate stays cheap because escalation fires rarely.
RouteLLM (2× cost reduction, no quality loss)
Independent confirmation that targeted escalation can hold quality while roughly halving cost vs always-strong.
