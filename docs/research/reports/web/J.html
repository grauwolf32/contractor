J · SCA / dependency-CVE correlation

Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

J1 — A dependency-manifest → known-CVE lookup tool adds true positives no current path can find

google/osv-scanner: lockfile → OSV vulnerability matcher (GitHub)
Drop-in reference: parses 19+ lockfile types across 11+ ecosystems, matches against OSV; the exact "manifest → known-CVE" tool J1 proposes, with a CLI to wrap or emulate.
OSV — Open Source Vulnerabilities (osv.dev)
Aggregates 30+ advisory sources (GHSA, PyPA, RustSec, …) into a precise version/commit-keyed schema with a free query API — the advisory DB backend for the lookup, no LLM cost.
google/osv.dev: open-source vuln DB + API (GitHub)
The queryable backend (by package+version or commit hash); documents the API the tool would call to emit structured dep-vuln findings.
OWASP Dependency-Check 2026: NVD-based SCA (AppSec Santa)
Alternative/complementary CPE-based matcher tied to NVD; useful where ecosystem advisories are thin, with the caveat that CPE matching is noisier (see J3).

J2 — Dependency-CVE leads focus the code-level trace on the vulnerable component, raising recall

Implementing SCA: Trivy + Reachability Analysis (SoftwareSeni)
Shows the pattern of pairing a manifest CVE hit with reachability/code analysis to confirm the vulnerable component is actually called — the dep-derived focus J2 wants to bias the trace toward.
SCA Reachability and the War on False Positives (ScanDog)
Explains using the CVE'd package + advisory to locate and confirm the reachable vulnerable code path — directly the "bias the code trace toward the pinned component" mechanism.
Learning to Triage Taint Flows Reported by Dynamic Analysis in Node.js Packages (arXiv)
Demonstrates using dependency-level vuln signals to focus deeper flow analysis on the implicated package — analogous to steering the trace agent using the dep-CVE lead.

J3 — SCA findings raise overall precision at ~zero model cost (deterministic source)

SCA vs SAST 2026: what each finds, misses, and costs (Konvu)
Frames SCA as a deterministic, high-precision lookup distinct from probabilistic SAST/LLM reasoning — supports that folding in SCA hits lifts aggregate precision without LLM spend.
SCA Reachability & FPs: a clearer path (ScanDog)
Quantifies SCA's precision profile and where its false positives come from (CPE vs ecosystem matching); guides keeping the deterministic findings near-100% precise.
OSV-Scanner: free vulnerability scanner for open-source software (Help Net Security)
Notes ecosystem-precise package matching (vs noisy CPE) keeps OSV findings high-precision — the property that makes SCA a near-free precision lift and low tokens/finding.
