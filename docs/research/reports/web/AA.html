Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

AA1 — Deterministic, context-targeted cell injection cuts resident skill context at equal recall

Equipping agents for the real world with Agent Skills (Anthropic)
Defines progressive disclosure: load only skill name/description until relevant, then full SKILL.md, then resources — the design rationale for injecting only the matching cell instead of whole bundles.
Agent Skills: Progressive Disclosure as a System Design Pattern
Frames progressive disclosure as a context-management pattern; cites 60–80% token reduction by loading only relevant skill layers — direct support for the resident-context-at-equal-recall claim.
skills-best-practices — lean context window skills
Practical guidance on authoring skills to keep the context window lean and validating them with LLMs — the implementation discipline AA1's targeted injection requires.

AA2 — A framework × class cell outperforms a generic class skill on framework-specific bugs

Semgrep Registry — rules organized by language, framework, and class
The Registry is literally a framework×class×language matrix (p/django, p/flask, p/express...), demonstrating that framework-specific rules outperform generic ones — the production analogue of the proposed cell.
Rule Writing for CodeQL and Semgrep (Spaceraccoon)
Shows how framework-aware rules encode ORM/route idioms (e.g. Django querysets) that generic rules miss — concrete evidence that Django-IDOR knowledge is more actionable than generic IDOR prose.
code-safety — taint benchmark on a controlled Django app (16 OWASP cases)
A ground-truth Django app comparing Pysa/CodeQL/Semgrep; a ready stratified fixture for measuring framework-cell vs generic recall on one framework.

AA3 — Task-specific skills as executable assets raise small-model success vs prose

Formal Skill: Programmable Runtime Skills for Efficient and Accurate LLM Agents
Represents skills as executable programs the agent invokes, gaining determinism (same input→same output) and testability — the core "asset, not prose" argument for procedural skills.
SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks
A benchmark for measuring skill effectiveness across tasks — the instrument to A/B procedural-skill-as-asset vs prose, including across model sizes.
SoK: Agentic Skills — Beyond Tool Use in LLM Agents
Systematization separating code-as-skill from prose instruction; reports retrieval-of-procedures beating free-recall (e.g. 80% vs 50% with BM25 baseline) — supports retrieval-beats-recall for small models.
SkillCraft: Can LLM Agents Learn to Use Tools Skillfully?
Studies whether agents can reliably execute multi-step tool sequences — relevant to packaging replayable probe sequences as executable assets.

AA4 — The framework/language axis closes the AST-vs-knowledge gap for under-covered languages

LLMs Versus Static Code Analysis Tools: A Systematic Benchmark for Vulnerability Detection
Benchmarks detection per language/class, exposing where coverage is thin — the substrate for measuring recall climb after adding a language cell (Rust/Kotlin/Swift).
Semgrep rule structure and taint mode (sources/sinks/sanitizers)
Shows that once AST/parse support exists, recall is gated by per-language sink/source knowledge encoded as rules — exactly the gap AA4 says a language cell fills.
A Comprehensive Study on SAST Tools for Android
Documents large per-language coverage variance (67% down to 22%) despite parser support — empirical evidence that knowledge, not AST support, bounds recall.

AA5 — A skill-coverage matrix makes gaps explicit; empty cells predict low recall

How to write and continuously test vulnerability-detection rules for SAST (GitLab)
Uses test-suites to measure rule-coverage gaps between analyzers with parity requirements — the methodology for turning cell-occupancy into a measurable, plannable surface.
SAST Coverage 101: what vulnerability types does SAST cover?
Frames coverage as a class×stack grid and notes large variability by stack — supports laying skills on a framework×class grid where occupancy predicts recall.
Agent Skills for LLMs: Architecture, Acquisition, Security, and the Path Forward
Survey of how skill libraries are organized, acquired, and gap-filled — frames coverage as a roadmap surface and warns against benchmark-specific overfitting when filling cells.
