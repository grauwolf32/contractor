S · Compositional exploit-chain reasoning

Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

S1 — A chain-search stage discovers multi-step exploits no single finding represents

From Sands to Mansions: Simulating Full Attack Chain with LLM-Organized Knowledge
Directly models the full multi-stage attack chain by having an LLM organize knowledge into linked steps — the clearest precedent for treating findings as composable nodes en route to high-impact states, as S1 proposes.
Guided Reasoning in LLM-Driven Pentesting Using Structured Attack Trees
Constrains LLM reasoning with deterministic attack trees (MITRE ATT&CK), an externalized search structure for chaining tactics — a concrete design for S1's pre/post-condition node search.
Automated Penetration Testing with LLM Agents and Classical Planning
Couples LLM agents with a classical planner to search for valid action sequences — the explicit graph/planning search over findings that S1 wants, with an evaluation of multi-step captures.
Graphene: Infrastructure Security Posture Analysis with AI-generated Attack Graphs
Generates attack graphs whose paths chain individual weaknesses into compromise routes — shows the node/edge representation (pre/post-conditions) S1 needs and that chains surface exploits no single node implies.

S2 — Chain-aware severity re-ranking surfaces critical paths scored low/medium per-finding

Vulnerability Management Chaining: A Framework for Risk Prioritization
Builds prioritization by chaining findings and aggregating exploitability/impact across the path — exactly S2's "re-score by worst reachable chain state," with the integrated severity framework.
Attack Path Prioritization (ThreatNG)
States the core S2 claim plainly: a "Medium" bug on a vital attack path outranks a "Critical" isolated one; introduces choke-points where many paths converge — a re-ranking signal beyond per-finding CVSS.
A Survey on Vulnerability Prioritization: Taxonomy, Metrics, and Research Challenges
Surveys prioritization metrics and why isolated CVSS misranks chained risk — grounds S2's "ranking correlation with true impact" metric and the limits it must beat.
What is CVSS? (Wiz)
Reference on the per-finding baseline scoring that S2 re-ranks against, including documented gaps when scoring vulnerabilities in isolation rather than along an attack path.

S3 — Chain reasoning is where small models most need externalized search (gap test)

Why Reasoning Fails to Plan: A Planning-Centric Analysis of Long-Horizon Decision Making in LLM Agents
Documents that LLMs degrade sharply on long-horizon planning — the core gap S3 bets on, motivating why externalized search should help the long-horizon chain task disproportionately.
ToolTree: Efficient LLM Agent Tool Planning via Dual-Feedback MCTS
Externalizes multi-step tool planning into an MCTS search "without retraining," improving accuracy per unit compute under a fixed budget — the externalized-search mechanism S3 would attach to a small model.
MCTS with Reasoning-Path Refinement for Small Language Models
Specifically targets small LMs: an external MCTS search compensates for weaker intrinsic reasoning — direct support for S3's prediction that uplift is larger for the 27b than the 70b.
PentestEval: Benchmarking LLM-based Penetration Testing (stage-level)
Notes LLMs "struggle to recognize attack chains and transfer reasoning across modules" and provides a stage-level harness — useful both as S3 evidence and as a benchmark to run the 2×2 model×search test.
