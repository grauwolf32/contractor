W · Planner architecture — keep the split, change the engine

Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

W1 — Planner tokens are a large, measurable fraction of total (the ReAct re-send tax)

AI Agent Loop Token Costs: How to Constrain Context (Augment Code)
Explains the O(N²) re-send tax: every loop step re-bills the full accumulated context/system prompt; cites an audit where re-sent context was 62% of the bill — directly sizes "the planner's re-sent prompt is the dominant sink".
AI Agents Burn 50x More Tokens Than Chats (LeanOps)
Quantifies how agentic loops blow up token budgets relative to single-shot use, with cost attribution by role — useful framing for decomposing RUN_SUMMARY tokens planner-vs-worker.
Inside the Scaffold: A Source-Code Taxonomy of Coding Agent Architectures (arXiv 2604.03515)
Taxonomizes where agent scaffolds spend tokens (planning loop, context re-injection, summarization) — supports attributing cost by agent role across workflows.

W2 — Deterministic fan-out for known-structure tasks preserves context isolation at ~zero planner cost

Task Planning and Decision-Making for LLM Agents (ACM AIIP)
Contrasts deterministic/PDDL decomposition (cheap, reliable on structured domains) with LLM planning (needed only for unstructured tasks) — backs using deterministic decomposition where structure is predictable (per-path/per-operation), exactly trace-direct generalized.
Plan-and-Execute Agents (LangChain)
Describes front-loading planning then executing subtasks with a cheaper/no-LLM execution path, keeping each worker's context narrow — the "one small slice per worker, no per-step planner" pattern W2 proposes.
Planning: Task Decomposition and Goal-Directed LLM Agents
DAG-based decomposition where independent subtasks fan out for parallel execution; the planner emits structure, workers run isolated — matches the deterministic per-finding fan-out with preserved worker context.

W3 — Plan-once + deterministic execution, re-plan only on failure, beats per-turn ReAct

An LLM Compiler for Parallel Function Calling — LLMCompiler (arXiv 2312.04511, ICML 2024)
Plans the whole task DAG in a single LLM call then executes deterministically; reports up to 6.7x cost savings and 3.7x latency over ReAct with +9% accuracy — the strongest direct evidence that plan-once dominates the per-turn loop. Open-source: github.com/SqueezeAILab/LLMCompiler.
AI Agent Planning: ReAct vs Plan-and-Execute for Reliability
Quantifies LLM-call counts: ReAct ~5-7 calls vs plan-and-execute 3-4 (1 plan + execution), with replanning only on failure — the call-count delta W3 measures.
Architecting Resilient LLM Agents: Secure Plan-then-Execute Implementations (arXiv 2509.08646)
Details plan-then-execute with failure-triggered replanning and its brittleness tradeoff — the exact "re-invoke planner only when a subtask fails" recovery mechanism, plus its failure modes to guard against.

W4 — A compact-state planner (indexes, not full artifacts) cuts per-turn tokens with no quality loss

Reducing Token Usage of State-in-Context Agents using Minification (arXiv 2606.01326)
Shows feeding the agent a minified/compact state instead of full context substantially cuts tokens while preserving task quality — direct support for a planner that sees a compact index, not full artifacts.
Compaction vs Summarization: Agent Context Management Compared (Morph)
Reports 90-98% token reduction moving from verbose JSON to compact schema-aligned encodings, and that observation masking can beat summarization — concrete techniques for shrinking the planner's window.
Beyond Context Limits: Subconscious Threads for Long-Horizon Reasoning (arXiv 2507.16784)
Maintains a compact working state for the controller while detail lives in workers/threads — the "planner keeps a tiny window, workers pull detail" discipline W4 applies to the planner.

W5 — Deterministic/compact planner + small-context workers dominates the ReAct planner on cost at equal quality

LLMCompiler (GitHub, SqueezeAILab)
Reference implementation of compile-then-execute agent architecture with measured cost/latency/accuracy dominance over ReAct — the end-to-end architecture template W5 synthesizes (plan-once + deterministic exec + isolated workers).
AI Agent Token Cost Optimization: Complete Guide 2026 (Fast.io)
Catalogs the combined levers W5 stacks — caching, scope-limiting, coordinator-specialist split, dropping redundant summarization — and their compounding cost effect at equal quality.
AI Agent Architecture Patterns: Single & Multi-Agent Systems (Redis)
Compares coordinator/specialist and plan-execute patterns on cost and reliability across both small and large backends — supports the mission-wide, both-model-sizes evaluation W5 calls for.

W6 — Decomposition driven by cheap structural signals (file tree, OAS paths, call-graph communities) without reading file contents

RepoSummary: Feature-Oriented Summarization for Code Repositories (arXiv 2510.11039)
Partitions repos using hierarchical clustering with community detection (Leiden) to group cohesive functionality into context-window-sized units — the structure-driven partitioner W6 needs, done from graph structure not file contents.
Codebase-Memory: Tree-Sitter Knowledge Graphs for LLM Code Exploration (arXiv 2603.27277)
Builds a call/knowledge graph with community discovery and impact analysis so the LLM navigates an index rather than raw files — "planner sees the map, workers read the slices", the key that makes W2/W4 non-circular.
Issue Localization via LLM-Driven Iterative Code Graph Searching (arXiv 2503.22424)
Navigates a code graph to localize relevant regions without ingesting the whole repo — evidence that structural partitioning achieves coverage (every region reachable) at near-zero planner content tokens.
Relative-Positioning Code Chunking for Repository-Level Context (arXiv 2510.08610)
Semantic-aware chunking at function/class boundaries (not arbitrary token cuts) so each unit stays digestible and coherent — addresses the kill condition where structure alone yields oversized/incoherent units.
