AX · Difficulty-aware search

AX1 — Classify capability failures separately from complexity barriers

What Makes a Good LLM Agent for Real-world Penetration Testing? (2026)
Analyzes 28 systems and separates Type A tool/knowledge failures from Type B complexity failures. Its typed Tool Layer alone raises XBOW completion from 54% to 68%, supporting class-specific recovery.
APT-Agent (2026)
Uses hybrid command rectification and command-specific memory to recover hallucinated commands while preserving operational context—an implementation pattern for the capability-failure branch.

AX2 — Calibrate remaining difficulty

PentestGPT v2: Task Difficulty Assessment
Estimates tractability from path and context signals before selecting attack goals; reports accuracy degradation beyond roughly 40% context load, making context pressure part of difficulty rather than an after-the-fact failure.

AX3 — External evidence-guided attack tree

PentestGPT v2: Evidence-Guided Attack Tree Search
Stores attack state externally and uses a UCB-style score over promise, exploration, and difficulty. This is direct prior art for testing an algorithm-owned tree against Contractor's prose/flat plans.
PenForge: On-the-Fly Expert Agent Construction (ICSE-NIER 2026)
Constructs contextual experts after reconnaissance and reports 12/40 exploit success on CVE-Bench zero-day mode, three times its stated prior baseline. Supports delayed specialization from observed path needs.
