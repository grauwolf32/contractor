AY · Ecological eval validity

AY1 — Measure degradation under benign distractors

The Emergence of Autonomous Penetration Capabilities in LLM-Powered AI Systems (2026)
Builds 300 target servers with Tier 1 and Tier 2 environments defined by one or three secure services deployed beside a vulnerable service. This directly motivates a distractor-density curve.

AY2 — Add clean-target and prevalence controls

GitHub Security Lab Taskflow auditing guidance (2026)
Production taskflows explicitly tell the auditor that no vulnerability may exist and require concrete file/line evidence, supporting secure twins and evidence-backed negative outcomes.
Microsoft MDASH (2026)
Reports production triage pressure, where every finding has an owner, alongside 21/21 planted vulnerabilities with zero false positives on a private driver. The claims are vendor-reported, but reinforce measuring low-prevalence operational precision.

AY3 — Score the full vulnerability lifecycle

CyberGym-E2E (ICLR 2026 Agents in the Wild Workshop)
Packages real OSS-Fuzz vulnerabilities in reproducible build environments and evaluates consecutive lifecycle stages with functionality testing; the paper reports an expanding dataset of 920 tasks.
GitHub Security Lab Taskflow Agent
An open-source, declarative taskflow framework using schema validation, checkpoints, retries, and targeted CodeQL context; a useful implementation comparator for reproducible staged evaluations.
