K · Triage, dedup & confidence calibration

Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

K1 — A triage/dedup stage across all finders raises precision at equal recall

Sifting the Noise: A Comparative Study of LLM Agents in Vulnerability False Positive Filtering
Directly on point: agentic LLM triage that iteratively gathers evidence drops OWASP-Benchmark FP rate from >92% to as low as 6%. Strong empirical case that a dedicated triage stage raises precision; also notes some agents over-suppress (recall risk to watch).
SastBench: A Benchmark for Testing Agentic SAST Triage
A benchmark purpose-built to evaluate agentic triage of SAST alerts — a ready harness/metric design for measuring the exact P/R/F1-before-vs-after that K1 proposes.
Semantic Similarity-Based Clustering of Findings From Security Testing Tools
Compares NLP semantic-similarity techniques for grouping security findings — prior art for replacing the brittle "CWE-" string split with cluster-based dedup that catches near-duplicates.
GitLab — Vulnerability deduplication process
Production reference for how a real platform merges findings across multiple scanners (location/identifier keys, precedence rules) — a concrete schema for a cross-finder reconciliation stage.
Assessing Validity of Static Analysis Warnings using Ensemble Learning
Classifier-ensemble approach to predicting true vs false warnings; shows the precision lift achievable by a learned post-filter, the non-agent analog of the triage stage.

K2 — Confidence is uncalibrated; calibration enables a predictable precision/recall knob

On Verbalized Confidence Scores for LLMs
Core evidence that self-reported (verbalized) confidence is systematically over-estimated for instruction-tuned models and highly prompt-sensitive — confirms VulnerabilityReport.confidence is unlikely to be calibrated as-is.
Systematic Evaluation of Uncertainty Estimation Methods in Large Language Models
Surveys/benchmarks UQ methods and reliability-diagram analysis; a methodology reference for binning findings by confidence and computing per-bin TP rate + calibration error (ECE/AUC).
Confidence Calibration in LLMs (survey/topic overview)
Overview of reliability diagrams, ECE, temperature/isotonic recalibration — the toolkit needed to turn a miscalibrated score into a monotone precision/recall threshold.
LLMs Encode Their Failures: Predicting Success from Pre-Generation Activations
Shows internal signals predict correctness better than verbalized confidence — an alternative recalibration source if verbalized confidence proves unfixable on small models.

K3 — Triaging before the dynamic stage cuts verify/exploit token spend

UCCI: Calibrated Uncertainty for Cost-Optimal LLM Cascade Routing
Maps token-margin uncertainty to per-query error probability via isotonic regression and picks an escalation threshold by constrained cost minimization — the exact recipe for a calibrated gate that prunes low-value findings before the expensive stage.
LLM Routing and Model Cascades: Cut AI Costs Without Sacrificing Quality
Practitioner overview reporting 45–85% cost cuts at ~95% quality via cheap-first/escalate-on-low-confidence cascades — the cost-saving mechanism K3 bets on, framed as routing.
Improving Model Cascades Through Confidence Tuning
Shows tuning the confidence/deferral signal materially improves the cost-accuracy frontier of a cascade — supports the claim that calibrated triage prunes spend at small recall cost.
GitLab 18.10 — AI-native triage and remediation
Industry deployment: an LLM estimates FP-likelihood so teams focus expensive effort on probable-true findings first — the same prune-before-expensive-work pattern in production.
