O · Self-improving experience memory

Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

O1 — Priming a run with a RAG index of past confirmed findings + FP patterns raises precision

ExpeL: LLM Agents Are Experiential Learners
The flagship prior art: an agent autonomously harvests insights from past task trajectories and recalls them at inference, consistently beating ReAct/Act with no parameter updates. The capability-compounds-without-fine-tuning thesis O is built on.
ReasoningBank: Enabling agents to learn from experience (Google)
Distills both successes and failures into reusable strategy items retrieved on similar tasks — directly models "inject prior leads + anti-patterns," and reports cross-run improvement.
How Memory Management Impacts LLM Agents: Experience-Following Behavior
Key caveat for O1's leakage/quality guard: agents exhibit "experience-following" — similar input retrieves similar output — but error propagation and misaligned replay can degrade performance. Argues memory curation, not just retrieval, drives the precision gain.
Learning When to Remember: Risk-Sensitive Bandits for Abstention-Aware Memory Retrieval in Coding Agents
Adds a decision layer on whether a retrieved memory is safe to use — supports deterministic/keyed retrieval (Direction Z) over blind vector recall, and guards against priming that injects bad leads.

O2 — Auto-mining eval false positives into anti-patterns reduces those FP classes

Experiential Reflective Learning for Self-Improving LLM Agents
Reflective loop that turns failures into preventative lessons reused on later runs — the mechanism for converting each scored FP into a stored "looks-like-bug-but-isn't" note.
Giving an AI Agent Memory of Its Past Failures
Hands-on account: episodic error-learning records (error pattern + realization) prevent repeating identical mistakes. A practical template for the FP anti-pattern store and how to key it.
500 Agent Memory Experiments: The Real Problem Was Binding
Empirical caveat: filtering noisy memory entries cut false positives 40%; the hard part is binding (which memory to apply when), not recall. Tells O2 that anti-pattern mining must include curation/typing, or it backfires.

O3 — Experience memory helps small models more than large (substitutes for parametric knowledge)

Retrieval-Augmented Generation: A Comprehensive Survey (RETRO datapoint)
Cites RETRO: a 7.5B model + retrieval matched a 175B model — retrieval substituting for ~20× more parameters. The clearest evidence the memory uplift is largest where parametric knowledge is smallest, exactly O3's mission-asymmetry claim.
Can Small Language Models Use What They Retrieve? An Empirical Study Across Model Scale
Important counter-nuance: at small scales the bottleneck is the "use" step — small models may retrieve but fail to utilize, and standard instruction-tuning is insufficient for grounding. Suggests O3's uplift is real but contingent on retrieval format/training; test, don't assume.
A Survey on the Memory Mechanism of LLM-based Agents
Taxonomy of agent memory designs (read/write/management) — a reference for choosing a deterministic, structured store that varies the memory-on/off variable cleanly for the 2×2 model-size experiment.
