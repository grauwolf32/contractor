U · Value-of-information attention policy

Web-sourced prior art, tools, papers and articles relevant to this direction. Links are real web-search results; relevance notes are the researcher's synthesis.

U1 — Adaptive allocation reaches equal recall at lower total tokens than flat max_steps

Spend Less, Reason Better: Budget-Aware Value Tree Search for LLM Agents (arXiv 2603.12634)
Training-free inference-time framework (BAVT) that models multi-hop tool-use as a value-guided search tree and shifts from exploration to exploitation as budget depletes; reports matching baselines that use 4x the resources — direct evidence adaptive allocation hits equal quality at lower cost.
Anytime Verified Agents: Adaptive Compute Allocation under Budget Constraints (OpenReview)
AVA dynamically splits a user-specified budget across search/sampling/verification using calibrated uncertainty and estimated marginal reliability gains — a concrete VoI controller for agentic tool use, the closest analog to replacing flat max_steps.
Budget-Aware Tool-Use Enables Effective Agent Scaling (arXiv 2511.17006)
Shows agents explicitly conditioned on remaining budget scale more favorably than fixed-step agents; supports the thesis that adaptive allocation pushes the cost/quality Pareto frontier.
Utility-Guided Agent Orchestration for Efficient LLM Tool Use (arXiv 2603.19896)
Frames tool/action choice as a utility (value-of-information) maximization for orchestration — the meta-policy abstraction this direction proposes, applied to tool selection.

U2 — Prioritizing by attack-surface / complexity / churn finds high-severity bugs earlier

Shin & Meneely et al., Evaluating Complexity, Code Churn, and Developer Activity as Indicators of Vulnerabilities (NCSU / IEEE TSE)
Canonical empirical study: a model on complexity+churn+developer metrics predicted ~70.8% of known vulnerabilities by inspecting only 10.9% of files — the quantitative basis for using these signals as ordering priors to get steep early recall@budget.
Vulnerability Prediction Based on Weighted Software Network (arXiv 1902.04844)
Uses call-graph/network structure (centrality on the dependency graph) to rank likely-vulnerable components — supports prioritizing by attack-surface graph position rather than flat enumeration.
Incorporating Fault-Proneness Estimations into Coverage-Based Test Case Prioritization (arXiv 1908.06502)
Demonstrates that injecting fault-proneness priors into prioritization improves early fault detection (APFD) — the test-ordering analog of recall@small-budget the hypothesis measures.
POLAR: Automating Cyber Threat Prioritization through LLM-Powered Assessment (arXiv 2510.01552)
Recent LLM-based prioritization/triage that ranks findings by exploitation likelihood and impact — shows the prioritization layer can itself be LLM-driven, relevant to how the policy scores regions.

U3 — Value estimates give a stopping signal that avoids the over-budget spiral

Assessing Reliability of Statistical Maximum Coverage Estimators in Fuzzing (arXiv 2507.17093)
Models the coverage plateau / diminishing-returns curve and defines a coverage-increment threshold for "point of diminishing returns" — a concrete marginal-yield stopping criterion transferable to "stop when expected marginal finding < threshold".
Optimal Stopping for Sequential Bayesian Experimental Design (arXiv 2509.21734)
Formulates stopping + design as coupled decisions in an MDP: stop when immediate terminal reward exceeds expected continuation value — the principled (non-myopic) VoI stopping rule the hypothesis wants, contrasted against fixed-threshold rules.
FOX: Coverage-Guided Fuzzing as Online Stochastic Control (arXiv 2406.04517)
Casts campaign continuation as online stochastic control over expected coverage gain — a working instance of deciding to keep spending vs stop based on estimated marginal value.
MABFuzz: Multi-Armed Bandit Algorithms for Fuzzing (arXiv 2311.14594)
Bandit allocation across fuzzing targets with reward = marginal coverage/crashes; its UCB-style value estimates double as the per-region yield estimate that feeds both prioritization (U2) and a stopping signal (U3).
